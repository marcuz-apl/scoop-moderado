# scoop-moderado

Scoop bucket for [Moderado](https://github.com/marcuz-apl/moderado) (free-first AI coding agent).

```powershell
scoop bucket add moderado https://github.com/marcuz-apl/scoop-moderado
scoop install moderado
```

`bucket/moderado.json` is generated from verified release checksums by
`npm run generate:manifests` in the main repo and pushed here by CI on each
release. Binaries are unsigned; Windows SmartScreen may warn on first run.
